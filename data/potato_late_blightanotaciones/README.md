# Dataset de tizón tardío en papa

- **Imágenes:** 600; 300 `healthy` y 300 `late_blight`.
- **Particiones:** train 420, val 120 y test 60.
- **Balance:** 50/50 en cada partición.
- **Clase de objeto:** `late_blight` (ID 0).
- **Formato:** YOLO.
- **Etiquetas:** las imágenes `healthy` tienen archivos vacíos y las imágenes `late_blight` contienen cajas delimitadoras.
- **Fila YOLO:** `class_id x_center y_center width height`, con coordenadas normalizadas.
